# CareerSathi AI

CareerSathi AI is an AI-powered career counseling platform for rural and underserved students.

- IBM watsonx.ai
- Knowledge Base

- Chroma DB
- Granite / Llama Models
- Netlify
- HTML, CSS, JavaScript

## Features
- Career Discovery
- Skill Gap Analysis
- Learning Roadmaps
- Placement Guidance
- Higher Education Guidance
- Scholarship Recommendations
